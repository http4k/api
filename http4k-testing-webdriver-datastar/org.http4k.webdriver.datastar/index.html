DatastarBehaviour
Link copied to clipboard
class DatastarBehaviour(http: HttpHandler, autoSettle: Boolean = true, plugins: List<DatastarPlugin> = emptyList(), navigate: (Uri) -> Unit = {}) : PageBehaviour

A PageBehaviour simulating a browser running datastar: it keeps a signal store, applies datastar-patch-elements/patch-signals SSE events to the live document, and sends non-local signals with every backend action. It models datastar's attributes through the built-in plugins, plus plugins, which add to them or replace a built-in of the same name; a navigation a plugin asks for is handed to navigate, relative to the page's base.
