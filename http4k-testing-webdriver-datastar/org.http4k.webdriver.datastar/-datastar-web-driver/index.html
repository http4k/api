DatastarWebDriver

class DatastarWebDriver : WebDriver(source)

A headless, pure-Kotlin approximation of a browser running datastar v1: an Http4kWebDriver with a DatastarBehaviour plugged in, so navigation, history and cookies all work as standard. plugins add to the parts of datastar it models, or replace a built-in plugin of the same name.
